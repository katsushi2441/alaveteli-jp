# Alaveteli 日本語導入キット（Docker 開発環境編）

情報公開請求（行政文書の開示請求）をオンラインで行い、請求文と行政機関からの回答を公開・検索できるようにする——英国 mySociety の **Alaveteli**（WhatDoTheyKnow の中身・AGPL-3.0）を、日本語で動かすためのキットです。当社が公式の Docker 環境で実際に立て、日本語の既定ロケールでトップ・行政機関一覧・請求フォーム・ヘルプが表示されるところまで実測した記録から起こしました。

**正直な範囲**: 公式の Docker 構成は開発環境向けです（本家も「開発用」と明記）。本キットは「日本語版を手元／VPS で動かし、行政機関を登録して請求ページが日本語で動くまで」を扱います。本番公開（HTTPS・メール受信・バックアップ）は別途の構築が要ります。

## 中身

- `01-構築手順書.md` … 本体。Docker で構築→日本語を既定に→行政機関の登録→請求フォームの動作確認。落とし穴6個
- `AI-START-HERE.md` … Claude Code 等の AI エージェントに渡すと設置を任せられる指示書
- `prompts/` … 設置後に AI に頼む作業の指示文（行政機関の一括登録・サイト名の変更・本番公開の相談）
- 日本語訳は本リポジトリ `locale/ja/app.po`（1,467/1,553 文字列。本家に PR 済み）

## 前提

Docker が動く VPS か自社サーバー（共有レンタルサーバーでは動きません。Ruby on Rails＋PostgreSQL＋Redis＋Xapian）。初回のイメージ構築に 10〜20 分、メモリ 2GB 以上を推奨。
