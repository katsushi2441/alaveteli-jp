# Alaveteli 日本語版 構築手順書（Docker 開発環境編）

実測環境: Ubuntu 22.04、Docker 28.4、Docker Compose v2.39、本家 `develop` ブランチ（2026-09-07）。日本語既定でトップ・行政機関一覧・請求フォーム・ヘルプの表示を確認。

## 1. 準備

```bash
git clone https://github.com/katsushi2441/alaveteli-jp.git
cd alaveteli-jp
mkdir -p ../alaveteli-themes        # compose がこの相対パスをマウントする（無いと起動時にエラー）
docker compose version
ss -ltn | grep -E ':3000 |:18383 '   # 使うポートが空いているか
```

公式の `docker-compose.yml` は app を **3000** 番で公開します。他のサービスが 3000 を使っていたら、同梱の `docker-compose.override.yml`（18383 の例）を書き換えてください。

## 2. 構築

```bash
./docker/setup        # イメージ構築・gem インストール・DB 作成・Xapian 索引。10〜20分
```

`config/general.yml` は `config/general-alavetelitheme.yml` へのシンボリックリンクとして作られます。次を書き換えます。

| 項目 | 値 |
|---|---|
| `AVAILABLE_LOCALES` | `'ja en'` |
| `DEFAULT_LOCALE` | `'ja'` |
| `SITE_NAME` | 例: `'情報公開請求アーカイブ（検証）'` |
| `DOMAIN` | 例: `'127.0.0.1:18383'`（公開時は実ドメイン） |

## 3. 起動と日本語の確認

```bash
./docker/server       # フォアグラウンド。バックグラウンドなら nohup ./docker/server &
curl -s http://127.0.0.1:18383/ | grep -c 請求     # 0 でなければ日本語化OK
```

翻訳ファイル `locale/ja/app.po` は起動時に読み込まれます。**後から差し替えた場合は `docker compose restart app sidekiq`** が要ります。

## 4. 行政機関の登録

`/admin` の「Authorities」（行政機関）から、名前・請求先メール・略称を登録します。CSV での一括登録も管理画面にあります。管理者は開発用の初期データに含まれます（`./docker/setup` の seed。パスワードは `docker/setup` の出力か `db/seeds.rb` を参照）。

## 5. 動作確認

- `/`：トップが日本語（「すべての市民には、行政機関が保有する情報にアクセスする権利があります」）
- `/body/list/all`：行政機関一覧
- `/select_authority`：行政機関を選んで請求フォームへ
- `/help/about`：ヘルプ

## 6. 本番へ向けて

公式の Docker 構成は開発環境向けです。本番は mySociety の公式インストール手順（Ubuntu への直接インストール）か、`docker/Dockerfile` を土台に production 設定・HTTPS（Caddy 等）・SMTP/IMAP（請求の送信と回答の受信）・バックアップを整えてください。日本の自治体はメールでの請求を受け付けない場合が多いので、「請求文と回答を公開するアーカイブ」としての運用を想定するのが現実的です。

## 落とし穴（実測）

1. **`../alaveteli-themes` が無いと起動しない**（compose が相対パスでマウント）。空ディレクトリで可
2. **ポート 3000 の衝突**。override で変える
3. **日本語にならない**＝`AVAILABLE_LOCALES` に `ja` が無い／`DEFAULT_LOCALE` が `en`／翻訳差し替え後に再起動していない
4. **初回構築が長い**（Ruby イメージ構築＋gem）。10〜20分は正常
5. **翻訳に約86件の英語が残る**（`<strong>` 入りのヘルプ文）。運用に支障はない。直す場合は `locale/ja/app.po` を編集して再起動
6. **開発用 smtp コンテナはダミー**。請求メールは外に出ない。本番は SMTP/IMAP と MX の設定が要る
